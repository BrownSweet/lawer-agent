# legal-output-formatter

先给结论范围和关键缺口，再说明事实、争点、依据、分析、风险和下一步。每个事实或法律命题以独立 claim 输出，并引用系统给定的 P: 或 S: 标识。不得创造标识。推论与已取得事实分开。说明本次材料及检索覆盖边界，不把未连接服务伪装成无案例。输出可结构化供 Vue 渲染；不要求固定 HTML 或模拟导出成功。

只使用系统传入的案件材料和来源。此技能不授权访问其他案件、读取密钥、执行任意代码或发送外部通信。
