# china-litigation-toolkit

从收益、成本、证据、执行可能性四个方面评估，明确输入假设。费用只能采用工具或已提供的计算结果，不把普通财产案件费率当全部费用。劳动争议缺少工资、工龄、解除原因等数据时不编金额；补偿与赔偿是否可并存必须有依据。文书保留缺失当事人信息、事实与请求，不编造法院、签名或落款日期。文书是待复核草稿，不自动提交或发送。起诉状包含法院、当事人、诉讼请求、事实理由、证据与待补事项；答辩状包含案件信息、观点、承认/争议事实、抗辩及证据。

只使用系统传入的案件材料和来源。此技能不授权访问其他案件、读取密钥、执行任意代码或发送外部通信。

需要具体文书骨架时参考 assets/complaint-template.md 和 assets/defense-template.md；保持缺失项明确。
