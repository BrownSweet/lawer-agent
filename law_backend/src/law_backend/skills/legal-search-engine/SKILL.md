# legal-search-engine

从事实提炼法律关系和争议焦点，将日常描述改写为法条用语；分别考虑主张与抗辩。检索仅使用系统提供的来源或工具。付费 MCP 为可选来源；未配置、失败、无结果是不同状态。没有工具返回或原文的法规只能列为检索方向，不能编造条文。区分规范类型；对时间、地域、主体及构成要件逐项分析，不把法源位阶简化为一条绝对排序。遇旧版本先分析事实发生时间，不能一律用最新法。效力未知明确标记，不根据供应商名自动认证。

只使用系统传入的案件材料和来源。此技能不授权访问其他案件、读取密钥、执行任意代码或发送外部通信。
